一套介绍，
多种合作场景。

完整母版同时支持老板快速看全景、商务按客群找方案、产品技术查目录。核心内容与版式分离，新增案例与更新数据不会破坏视觉统一。

怎么使用

使用场景推荐路径
老板与战略讨论总体蓝图 → 产品组合 → 成效与里程碑 → 合作方案与商业模式
C端条线与生态合作客群入口 → 需求与方案 → 对应演示 → 服务接力与试点
AI产品、科技平台开放能力 → MCP / Skills → 接入案例 → 标准订阅或企业授权
金融机构、顾问团队与商户对应客群方案 → 顾问 / 投研 / 内容场景 → 试点验收 → 扩展路径

页面支持章节跳转、产品搜索、案例切换与放大、平台筛选、方案引导、价格预算、需求简报复制与下载、演示模式和打印。演示模式可使用左右方向键切换章节，Esc退出；打印会展开案例和主要内容。

怎么更新

  1. 打开“盈米AI-内容维护工作台.html”，选择产品、客群、案例、价格或数据。
  2. 修改字段后保存。新增案例可上传图片，并填写“官方演示”或“模拟效果”及来源说明。
  3. 点击“预览新版”，检查数字、文字和图片；点击“导出完整HTML”获得可离线使用的新版本。
  4. 同时导出“内容底稿”留档。草稿仅保存在当前浏览器，本地文件请自行备份。
  5. 需要更新线上版时，将完整HTML或内容底稿交给Codex，并说明“更新盈米AI商务母版并发布”。线上版本不会被本地草稿自动替换。

统一的视觉语法

白与淡灰为内容底色，蓝色标识能力与路径，浅绿色标识行动与关键结果；大标题负责战略叙事，网格与表格负责对照，真实截图与模拟效果都使用同一外框与素材标签。模拟图标准画布1280×800，所有数字写明示意。

本版的事实边界

资料核验日为2026-11-09。公司指标、AI平台指标与产品效果保留各自统计时点；工具目录是公开README中的69项快照，Skills为公开路由示例，不代表所有平台当前权限。竞品表是公开定位对照，未做同样本效果评测。

百炼三SKU价格为公开页面核验值；1000 credits为额度，不是1000次调用。自助订阅默认供订阅主体内部使用。分发、企业SLA、高并发与定制另洽；一次业务任务可能调用多个工具，模型、云资源与实施不包含在工具估算中。

内部客户项目、个别合同价格、采购进度与未证实平台状态仅保留在本地内部底稿，未进入公开网站、源码包或下载附件。网页中的方案建议不代表所有能力均为已标准化商品；企业交付按实际方案约定。
